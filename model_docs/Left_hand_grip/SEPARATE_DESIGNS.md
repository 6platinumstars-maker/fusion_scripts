# 3デザインへの分離

## 基準版

留金部の個別フィレット修正後、ユーザーが1・2の全体生成と3のガイドライン表示を確認した版を基準とする。退避先: `/home/ps/fusion_backups/working_before_split_20260927.tar.gz`。

## 変更範囲

- 1は内殻本体と蓋部回転切り取りのみを生成する。
- 2は保存済み参照形状と従来と同じ外殻生成手順を使う。
- 3から全体生成モジュールへの依存を除去する。
- `inner_shell.py`、`outer_shell.py`、`grip.py` の形状生成本体は分離作業で変更しない。
- 空のデザインを要求し、既存モデルを自動削除しない。グリップ専用属性のあるガイドラインデザインだけ再実行を許可する。

## 参照の受け渡し

1の本体生成後、最終回転切り取り前の各ボディをSMT形式でローカル保存する。この段階は旧全体生成で外殻が参照した段階と同じ。最終内殻の処理が成功してから最新参照を公開する。過去の参照は版別のフォルダに保持する。

2は起動時に固定参照を検証して一時BRepとして読み込み、外殻デザインのルートへ追加する。履歴ありの場合はベースフィーチャを使い、追加コンポーネントを作らない。参照の名前を復元して既存の外殻参照解決を利用する。参照形状は外殻デザイン内に保存され、他のデザインに依存しない。完成時に参照ボディと補助スケッチ・平面を非表示にする。

`fusion_scripts_build` デザイン属性の `role`、`code_revision`、`reference_revision` で生成元を追跡する。コードが更新されても既存デザインの内容は変わらない。2の再生成時にのみ、その時点の最新参照を取り込む。

## ユーザー確認手順

1. 既存の正常モデルを保存しておく。
2. 同期後にFusionを再起動する。
3. 空のデザインで1を実行し、内殻だけが表示されることを確認する。
4. 別の空のデザインで2を実行し、外殻だけが表示されることを確認する。
5. 別の空のデザインで3を実行し、指A〜Dのガイドラインを確認する。
6. 内殻・外殻・グリップの3デザインとして保存する。既存の正常版を置き換えるのは確認後とする。

2の初回実行には、新しい1で作成する参照キャッシュが必要。旧1で保存したFusionファイルだけではこのキャッシュは作られない。別のPCへ移行する場合は参照キャッシュを移すか、1を再実行する。
