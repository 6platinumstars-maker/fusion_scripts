## 外殻の３Dプリント用微調整（2026-09-30・全4工程完了／Fusion確認済み）

`2` の外殻生成で、接合部切かけの後に次の4工程を実行します。訂正後の3点平面による分割・三角錐除去を含め、全工程をユーザーがFusionで確認済みです。

1. Z=-3.2 mmのXY面を-Z方向へ0.5 mm切取り（終端Z=-3.7 mm）。
2. X=0 mmのYZ面を+X方向へ0.5 mm結合押し出し（終端X=0.5 mm）。
3. Z=-3.7 mmに中心(-22.452, -10.879, -3.7) mm・半径19 mmの円を作成。外殻全体をXY投影した外周内部と円の共通領域を、+Z方向へ13.3 mm切取り（終端Z=9.6 mm）。開始面に現れない奥の壁・埋もれた部分と内周の穴・空洞も含めます。

4. 指定3点を通る平面で外殻を分割し、角(-76.795, 32.2, -6.0) mmを含む三角錐側を除去。

工程名は「３Dプリント用微調整」です。詳細と実装・診断記録は [外殻の完成仕様](OUTER_SHELL.md) を参照してください。

- B: (-57.8, 32.2, -6.0)

実装: `fusion_app/outer_shell_corner_split.py`。診断: `outer_corner_split_diagnostics.json`。訂正後の上記3点による分割形状と三角錐側の除去を、ユーザーがFusionで確認済みです（2026-09-30）。加工名は「３Dプリント用微調整：4 外殻3点平面分割：三角錐除去」です。
