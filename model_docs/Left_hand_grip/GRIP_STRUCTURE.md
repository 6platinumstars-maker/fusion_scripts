# GRIP_STRUCTURE

`グリップ構造` の考え方と開発方針をまとめる README です。

この構造は `内殻` や `外殻` と違い、最初から厚みを持った閉じたボディとして作る前提ではありません。まずは点・線・面で構成された、一枚の折り紙のような展開構造として定義し、その後に `外殻基本構造` と隙間なく接続させることで、はじめて質量を持つ 3D プリント可能なボディとして成立させます。

補足:
この README では説明上 `外殻基本構造` という呼び方を使います。現行コード上の名称は `外殻基準構造` です。

## 構造の考え方

- `グリップ構造` は、点・線・面の関係で形を決める構造です。
- 初期段階では、厚みを持つソリッドというより、折り紙のような一枚構成のサーフェス的な扱いを前提にします。
- この一枚構成のエンド部分を `外殻基本構造` に隙間なく接続し、閉じた境界を成立させることで、最終的に質量を持つボディへ発展させます。
- したがって `グリップ構造` 単体の形状定義と、`外殻基本構造` への接続条件は、同じくらい重要な仕様として扱います。

## 基本方針

- `グリップ構造` の形状は、面の寄せ集めではなく、名前付きの点・線・面の関係として管理します。
- 各点・線・面には一意な名称を付けます。
- 寸法や角度は固定値として埋め込まず、外部入力で与えたり差し替えたりできる前提で管理します。
- `内殻` や `外殻基本構造` との位置関係も、外部から与える `X` `Y` `Z` 情報または参照情報として扱います。
- 将来的に形状調整が発生しても、名称付き要素と入力値を差し替えることで構造全体を再生成できる状態を目指します。

## 関節角度の名称（2026-09-25追加）

各指の角度を次の対応で定義します。表の `F` は指の記号 `A / B / C / D` に置き換えます（例：`F1θ` は `A1θ / B1θ / C1θ / D1θ`）。

| 角度名 | 対象となる平面・線 |
|---|---|
| `F0θ` | 平面 `FJ` と線 `G–FG1` の角度 |
| `F1θ` | 線 `G–FG1` と線 `FG1–FG2` の間の角度 |
| `F2θ` | 線 `FG1–FG2` と線 `FG2–FG3` の間の角度 |
| `F3θ` | 線 `FG2–FG3` と線 `FG3–FG4` の間の角度 |
| `F4θ` | 線 `FG3–FG4` と線 `FG4–FP` の間の角度 |

`F0θ` の基準平面は `FJ` とします（2026-09-25訂正）。指Aでは `AJ`、指Bでは `BJ`、指Cでは `CJ`、指Dでは `DJ` です。関節線を配置する平面は引き続き `FJ'` です。`FJ` と `FJ'` は直交し、直線 `G–FP` を共有するため、この定義では初期線 `G–FG1` の傾きに応じた角度を表せます。

角度の選択ルール（2026-09-25確定）：指A・B・C・Dのすべての角度 `F0θ`〜`F4θ` は、必ず小さい方の角度を採用します。これは角度の大きさのルールであり、曲がる向き・回転の正負とは区別します。

指A・Bの入力値と生成値は以下の試作表に記載します。指C・Dの関節長さ・角度の数値は未確定です。曲がる向きは次の候補選択ルールで決定します。指C・Dにも同じ命名を適用しますが、その基準点・基準平面も上記の指定座標で実装済みです。指A・Bは指定長さを維持し、角度を近似調整して関節線を生成します。

## 指の曲がる向き（2026-09-25確定）

- 各指の5区間からなる連続線は、平面 `FJ'` 上で `G` から `FP` までを結び、全体として半円のように曲がる形とします。ここで `F` は `A / B / C / D` です。
- 同じ長さ・角度を持つ2つの候補ができる場合、最初の関節点 `FG1` が内殻中心点 `O (-42.0, 5.0, 0.0) mm` から遠い方を選択します。
- 比較する値は、モデル空間での3次元直線距離 `distance(O, FG1)` です。指Aでは `AG1`、指Bでは `BG1`、指Cでは `CG1`、指Dでは `DG1` を使います。
- このルールは曲がる向きの選択に使い、各角度について小さい方を採用するルールは維持します。
- 「半円のような形」は全体の曲がり方を表します。厳密な円弧半径や、各区間を曲線として生成する方法はここでは定義しません。
- 2候補の `O–FG1` 距離が等しい場合の選択方法は未定義です。指A・Bの候補選択処理は実装済みです。

## 指Aのライン試作（2026-09-25）

`3.py` で `グリップ関節線：指A` スケッチを表示します。`AJ'` 上に `G → AG1 → AG2 → AG3 → AG4 → AP` の5本の直線を作り、参考線 `AGP` も追加します。線は補助線として作成し、点・線には名前属性を付けます。再実行時は同名スケッチを削除して再生成します。

|---|---:|---:|
| AL0 | 12 mm | 12 mm |
| AL1 | 25 mm | 25 mm |
| AL2 | 17 mm | 17 mm |
| AL3 | 11 mm | 11 mm |
| AL4 | 14 mm | 14 mm |
| A0θ | 80° | 84.413618° |
| A1θ | 126° | 119.197491° |
| A2θ | 160° | 157.480552° |
| A3θ | 135° | 129.331243° |
| A4θ | 150° | 146.220828° |

今回の126°などの指定は、関節点から両隣の点へ向かう2本の線分の小さい方の角（0〜180°）として扱います。進行方向の曲がり角は `180° − Aiθ` です。

入力値そのままではAPへ一致しないため、近似を許容する指示に基づき、5本の長さと始終点G・APを優先します。4つの曲がり角に共通係数（約1.125972384）を掛け、終点までの直線距離をAGPに合わせます。その後、全体を平面内で回転してAPへ向け、鏡像2候補のうちAG1とOの距離が大きい方を採用します。A0θは目標値として記録し、生成値は終点を合わせた結果から求めます。全角度の誤差を最小化する最適化ではありません。

値は `grip.py` の `GRIP_FINGER_A_LENGTHS_MM` / `GRIP_FINGER_A_ANGLES_DEG` にまとめています。`build_grip()` の `params` で `finger_a_lengths_mm` / `finger_a_angles_deg` を渡すこともできます。総曲がり角が180°以下の調整範囲で接続できない入力はエラーにします。

数値確認済み：長さ5本、G・APへの一致、AJ'上の配置、角度5個、Oから遠い側の選択。指AはユーザーによるFusion上の表示確認済みです。

## 要素の管理方針

### 点

- 主要点には名前を付けます。
- 各点は、絶対座標で固定するのではなく、基準点からの距離、角度、他点との関係で表せるようにします。
- 必要に応じて、`内殻` や `外殻基本構造` 上の参照点に従属させます。

### 線

- 線には始点・終点・接続先面との関係が分かる名前を付けます。
- 長さは外部入力値で変更できる前提にします。
- 線の角度も外部入力値または基準面に対する角度として管理します。

### 面

- 面には境界を構成する点・線が追える名前を付けます。
- 面は単独で閉じたソリッドを作るためではなく、折り曲げ前提の一枚構造を定義する単位として扱います。
- どの面が `外殻基本構造` への接続終端になるかを明示します。

## 外部入力として扱う情報

- 長さ
- 角度
- `X` `Y` `Z` 方向の位置情報
- 他ボディとの相対位置
- 接続先となる点・線・面の参照情報

これらは今後、`grip.py` 側でまとめて受け取れる形に整理していきます。

## 外殻基本構造との接続方針

- `グリップ構造` のエンド部分は、`外殻基本構造` と隙間なく接続する前提です。
- 接続がずれると、最終的に閉じたボディにならず、3D プリント可能な形状として成立しません。
- そのため、接続終端にある点・線・面は通常部より優先度の高い管理対象として扱います。
- 将来的には、接続面の一致、端点位置の一致、法線方向の整合を確認できるようにします。

## 現時点の実装方針

- `3.py` は `グリップ構造` 単体確認用の入口として使います。
- `fusion_app/grip_structure.py` は、必要な段階になれば内部的に `内殻` と `外殻基準構造` を参照生成してから `grip.py` を呼べる構成にします。
- ただし現時点の `3.py` は軽量な単体確認を優先し、参照ボディをまだ生成しません。`グリップ構造` だけを表示対象にします。

- 現在の `grip.py` は、上記の参照点・参照方向・参照平面を表示する初期実装まで入っています。
- 現在は `O / G / X / Y / 平面I / ±X / ±Y / ±Z` に加えて、指A・B・C・Dの `P / P' / J / J'` も表示できます。

## 実装時の最初の整理単位

1. 名前付きの基準点一覧を決める
2. その点を結ぶ基準線一覧を決める
3. 基準線から構成される面一覧を決める
4. `外殻基本構造` に接続する終端要素を特定する
5. 各要素に対して、長さ・角度・位置のどれを外部入力にするか決める
6. その情報を `grip.py` で再生成可能な形に落とし込む

現時点では 1 と 2 の最初の基準として、`O` `G` `X` `Y`、`GX` `GY` `GO`、`平面I`、および指A・B・C・Dの `P / P' / J / J'` の定義を開始済みです。
