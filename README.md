## 保存と実行手順

1. `./sync.sh` でWindows側のFusion Scriptsへ同期する。
2. Fusionを再起動し、新しい空のデザインで `1` を実行。内殻を確認して「内殻」として保存する。
3. 別の空のデザインで `2` を実行。外殻を確認して「外殻」として保存する。
4. 別の空のデザインで `3` を実行。ガイドラインを確認して「グリップ」として保存する。

保存するFusionデザインは上記3つを基本とします。再生成は空の作業デザインで行い、確認後に保存済みの版をどう残すか判断してください。スクリプトは既存の保存デザインを自動削除・上書きしません。1・2は既存形状があるデザインでは変更前に停止します。3は、この入口で作成したグリップ専用デザインでは再実行できます（現時点のガイドラインのみ）。旧全体モデルや旧3のデザインでは、新しい空のデザインを使ってください。

## 外殻の固定参照

1は、従来の全体生成が外殻へ渡していた「内殻蓋部回転切り取り前」の形状をローカルに保存します。内殻の最終処理が成功した場合だけ最新版として公開します。2はその固定コピーを読み込み、内殻の生成Pythonを実行しません。手作業の書き出し・読み込みは不要です。

- 保存先: Windowsの `API/Scripts/_grip_reference/`。Fusionクラウドの追加デザインではありません。
- 版ごとのSMT形状、ファイルハッシュ、生成コードのハッシュ、`latest.json` を保存。
- 2のデザインには参照ボディを保持し、完成時は外殻だけを表示。内殻デザインへのライブリンクはありません。
- 1を再実行しても、既に保存した外殻デザインは自動更新しません。2を新規実行したときだけ最新参照を使います。
- 各デザインの `fusion_scripts_build` 属性に役割、コードのハッシュ、参照版を記録します。
- `sync.sh` は参照キャッシュを削除・上書きしません。キャッシュが失われた場合は1から再作成します。

## 各ボディの説明

- `内殻`
  固定形状の基準ボディです。左手グリップ案件の土台であり、他ボディが参照する起点になります。
- `外殻`
  `内殻` をはめ込むための別ボディです。現在までに作成済みの本体は `外殻基準構造` として扱い、`内殻` の面や外形を参照して形状を決めます。
  `内殻` と接する面は、`外殻` 側を `0.2 mm` 逃がして隙間を設ける前提です。
- `グリップ`
  ここでは `グリップ構造` を指します。外部から取得する値に応じて寸法や形状が変わる可変ボディで、`外殻` と重なる部分をカットする参照にも使います。
  現時点ではボディ生成は未実装で、`grip.py` では `グリップ参照点：O / G / X / Y`、`グリップ参照方向：±X / ±Y / ±Z`、`グリップ参照点：平面I` を表示する段階です。

### `fusion_app/`

Fusion API を前提にした実装を置く場所です。左手グリップ案件では `inner_shell.py` / `outer_shell.py` / `grip_structure.py` / `grip.py` / `assembly_left_hand_grip.py` / `helpers.py` / `naming.py` を使います。`Left_hand_grip.py` は旧入口との互換性維持用として残しています。

作業の基本方針は次の通りです。

1. 案件ごとに `fusion_app/名前.py` を作る
2. その中で `run(context)` を入口にする
3. スケッチ作成、プロファイル選択、押し出し、探索処理を関数に分ける
4. `1.py` / `2.py` から呼び出して確認する

### `core/`

Fusion API の共通ヘルパーを置く場所です。個別案件のロジックを書き込みすぎず、複数スクリプトで再利用できる処理をここへ寄せます。

現在の `core/fusion_helpers.py` は次のような用途で使います。

- プロファイル取得
- ボディ取得
- 面・辺・頂点の探索
- 面上スケッチ作成
- 面の輪郭投影
- 幾何判定の共通化

### `model_docs/`

各モデルの説明を `モデル名/README.md` の形で整理するフォルダです。

現在は次のファイルがあります。

- `model_docs/Left_hand_grip/README.md`
- `model_docs/Left_hand_grip/GRIP_STRUCTURE.md`

モデル固有の面・辺・頂点の説明は、今後このフォルダ側へ集約します。
